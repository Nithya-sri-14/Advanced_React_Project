# ProTask Agile Studio (Advanced React Project)

A complete, production-grade Agile Kanban Task Management dashboard built with **React 18**, **Custom Hooks (`useReducer`)**, **localStorage state persistence**, and **Modern CSS**.

## Features
- **Kanban Task Board**: Categorized by To Do, In Progress, Review, and Done columns.
- **Custom `useTasks` Hook**: Handles task state mutations using `useReducer` and syncs with `localStorage`.
- **Interactive Modals**: Add new tasks with priority tagging (Urgent, High, Medium, Low).
- **Real-Time Analytics**: Header statistics card for completion rate and task counts.
- **WebContainer Ready**: Tested for WebContainer in-browser compilation and live preview.
